📌 Requisitos de API / Banco de Dados
1. Criar Novo Registr
Descrição: Realiza a inserção de um novo registro no banco de dados.

Operação: INSERT / Add

Parâmetros / Payload:

titulo (string)

data (datetime / date)

conteudo (text / string)

2. Listar Todos os Registros
Descrição: Retorna a lista completa de todos os registros históricos gravados.

Operação: SELECT

Query Base:

SQL
SELECT * FROM registros;
3. Buscar Registro Específico por ID
Descrição: Retorna os detalhes de um único registro a partir do seu identificador exclusivo.

Operação: SELECT com filtro

Query Base:

SQL
SELECT * FROM registros WHERE id = @id;
